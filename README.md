# 사이트홈드 3D (Sitehold 3D)

태블릿/모바일 최적화 1인칭 전술 슈팅 웹 게임 (Three.js 단일 HTML).

## 실행
브라우저에서 [`index.html`](./index.html) 을 열거나:

```bash
npx --yes serve .
```

## 조작
- **모바일/태블릿**: 왼쪽 이동 · 오른쪽 시점 · 사격/점프/특수 버튼 · ◀▶ 무기 전환
- **PC**: WASD · 마우스 시점 · 클릭 사격 · 우클릭 특수 · Space 점프

## 관리자
메뉴 → 관리자에서 인증 후 JavaScript로 맵/무기를 추가할 수 있습니다.
